## 音色切换

画 `set_timbre` 图案并在栈上放一个数字，即可切换画线音色。

| 数字 | 音色 |
|---|---|
| 0  | 默认（Hex 原版） |
| 1  | 钟 |
| 2  | 风铃 |
| 3  | 长笛 |
| 4  | 吉他 |
| 5  | 竖琴 |
| 6  | 木琴 |
| 7  | 铁木琴 |
| 8  | 牛铃 |
| 9  | 迪吉里杜管 |
| 10 | 电子叮 |
| 11 | 贝斯 |
| 12 | 军鼓 |
| 13 | 踩镲 |
| 14 | 芯片音 |
| 15 | 班卓琴 |

音高规则不受影响：
- 直走 → 中音
- 拐弯 → 音高随转角变化
- 回退 → 低沉提示音
